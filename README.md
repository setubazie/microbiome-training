# Microbiome Training — Demo Dataset

## About the Instructor

I'm Setu Bazie Tagele, a Research Specialist in the CORE Lab at Prairie View A&M University, studying microbiomes across soil, plant, animal, and human systems — with a particular interest in how microbial communities shape host and environmental health. My work spans 16S rRNA amplicon sequencing, shotgun metagenomics, metagenome-assembled genomes (MAGs), RNA-seq, and DNA methylation analysis, applied to questions ranging from how soil treatments reshape microbial communities to host-microbiome interactions more broadly (see Tagele et al.).

Beyond running these analyses myself, I enjoy breaking the pipeline down for others — turning dense bioinformatics into something a newcomer can actually follow and run independently. This repo is built from that training: real data, real commands, explained step by step.

## About This Repo

This is a demo dataset for the 16S rRNA amplicon sequencing training: 6 samples (2 treatments × 3 replicates), paired-end raw reads, 12 gzip-compressed FASTQ files (`.fastq.gz`) total.
